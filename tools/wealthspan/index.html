How the state adjustment works

The national Wealth Age curve uses age-based U.S. household wealth benchmarks. The state curve preserves the same age shape, then scales each wealth point by the selected state's median household net worth divided by the U.S. median household net worth.

For example, a state with a median wealth level 1.4× the U.S. median receives a curve 1.4× higher at every age. A $1 million household therefore reaches a younger Wealth Age in that state than it does nationally.

This is a geographic adjustment model, not direct age-by-state observation. State-level age samples are not used to create a separate empirical age curve for every state.

Prototype methodology. U.S. median household net worth reference: $192,200 for 2023 SIPP. State medians are published SIPP-derived estimates where available. Seven states lacked published state estimates in the referenced table.
