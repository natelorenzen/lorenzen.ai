# Purpose

This skill asks what evidence would prove us wrong. It treats every thesis, strategy, or forecast as a conjecture to be tested severely, not confirmed. It distrusts theories that can explain anything and values bold claims that risk refutation. This is a framework derived from Popper's published work. It does not simulate or speak for Karl Popper.

# When to Use

- Testing a strategic thesis, investment case, or business plan
- Situations where every new fact seems to "confirm" the team's view
- Designing experiments or pilots
- Evaluating experts or models that are never wrong

Do not use for:

- Decisions that must be made before any test is possible, except to design the fastest test

# Core Questions

- **What evidence would prove us wrong?** (MINDS summary, not a quotation)
- Is this claim falsifiable at all?
- Have we tried to refute it, or only to confirm it?
- Which bold conjecture would explain more and risk more?

# Documented Principles

| ID | Principle (MINDS' wording) | Provenance | Source |
|---|---|---|---|
| P1 | Confirmations are easy to find if we look for them. They count only as the results of risky predictions: outcomes that, without the theory, we would have expected to go against it. | DOCUMENTED | S1 |
| P2 | A theory that no conceivable event could refute is not scientific. Irrefutability is a vice, not a virtue. | DOCUMENTED | S1 |
| P3 | Every genuine test is an attempt to falsify. Some theories are more testable, more exposed to refutation, than others. | DOCUMENTED | S1 |
| P4 | The criterion of a theory's scientific status is its falsifiability, or refutability, or testability. | DOCUMENTED | S1 |
| P5 | Rescuing a refuted theory with ad hoc assumptions or reinterpretation destroys or lowers its scientific status. | DOCUMENTED | S1 |
| P6 | Knowledge grows through bold conjectures and attempted refutations. Criticism, not confirmation, is the engine. | DOCUMENTED | S1, S2 |
| P7 | The agent must state, for the leading thesis, the observable outcomes that would refute it and a test that could produce them. | OPERATIONALIZED | P3, P4 |

# Analytical Procedure

1. **State the thesis precisely.** Vague theses can't be tested.
2. **Falsifiability (P2, P4).** What observable outcome would show it's wrong? If none, the thesis is not yet testable.
3. **Risky predictions (P1).** Which of the thesis's predictions would be surprising without it? Only those count as support.
4. **Severe test (P3, P7).** Design the cheapest test most likely to refute the thesis if it is false.
5. **Ad hoc rescue check (P5).** Has the thesis been patched after earlier misses? Flag each patch.
6. **Rival conjectures (P6).** Propose a bolder alternative that would explain more, and what would distinguish the two.

# What This Framework Pays Attention To

- Testability and refutation conditions
- The difference between real and cheap confirmation
- Ad hoc patching of beliefs

# What This Framework May Underweight

- Action under uncertainty when no test is available in time
- Probabilistic reasoning and base rates (see Kahneman)

# Questions to Ask

- What would we have to see to abandon this plan?
- Which "evidence" would we have seen whether or not we were right?
- How many times has this thesis been reinterpreted after a miss?
- What is the bolder alternative explanation?
