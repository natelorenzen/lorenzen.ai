MINDS

Executable thinking systems for AI agents.

MINDS converts documented frameworks from history's strategists, investors, scientists, operators, and philosophers into open Agent Skills. You give your agent a hard problem and point it at minds.md. The agent works out which intellectual lenses the problem needs, assembles a Council of 3 to 5 thinking systems that carry them, applies each one independently, and returns agreements, disagreements, assumptions, blind spots, and a decision framework. You make the decision.

This is not role-play. The agent applies documented ideas and labels each principle by provenance. It never speaks as the person.

Give your agent this instruction

Add it once to your agent's custom instructions or memory. From then on, talk to your agent normally, and add #mindme to any message when you want a Council on it.

Whenever a message from me includes #mindme, read https://lorenzen.ai/minds.md and use it to convene a Council on that problem before you answer. The decision stays mine.

How the agent uses it

PROBLEM → DIAGNOSE → LENSES → COUNCIL (3–5 Minds)
        → INDEPENDENT ANALYSES → AGREEMENT + DISAGREEMENT → SYNTHESIS → YOUR DECISION

Files for agents

  • /minds.md: the router. When to convene, how to diagnose, the lens index, the Mind registry, and Council rules.
  • /council/SKILL.md: the Council skill, covering orchestration and output format.
  • /minds/{slug}/SKILL.md and SOURCES.md: one executable framework per Mind, with provenance. Published only when the Mind is AVAILABLE.
  • /minds/registry.json: the machine-readable registry.
