# Purpose

This skill examines how the description of a choice shapes the choice. It asks where the reference point is, whether losses are weighing more than equivalent gains, whether a different frame would reverse the preference, and whether certainty is being overvalued. This is a framework derived from Tversky's published research, much of it with Daniel Kahneman. It does not simulate or speak for Amos Tversky.

# When to Use

- Choices presented as gains or losses, such as pricing, offers, negotiations, and risk communication
- Decision-makers who seem unusually risk-averse or risk-seeking
- Designing how options are presented to customers or stakeholders
- Probability estimates in the team's own analysis

Do not use for:

- Organizational politics or structure (see Machiavelli, Sloan)

# Core Questions

- **How is the framing shaping the choice?** (MINDS summary, not a quotation)
- What is the reference point, and would a different one change the decision?
- Are losses being weighted more heavily than equivalent gains?
- Is a sure outcome being overvalued relative to a probable one?

# Documented Principles

| ID | Principle (MINDS' wording) | Provenance | Source |
|---|---|---|---|
| P1 | People evaluate outcomes as gains and losses relative to a reference point, usually the current position, not as final states of wealth. | DOCUMENTED | S1 |
| P2 | The value function is concave for gains, convex for losses, and steeper for losses than for gains (loss aversion). | DOCUMENTED | S1 |
| P3 | Certainty effect: outcomes that are certain are overweighted relative to merely probable ones. This produces risk aversion for sure gains and risk seeking for sure losses. | DOCUMENTED | S1 |
| P4 | Isolation effect: people discard components shared by all options, so how a choice is decomposed changes the preference. | DOCUMENTED | S1 |
| P5 | Framing: logically equivalent descriptions, such as lives saved versus lives lost, reliably produce different choices. | DOCUMENTED | S2 |
| P6 | Judgment heuristics (representativeness, availability, and anchoring) produce systematic errors in probability estimates. | DOCUMENTED | S3 |
| P7 | The agent must restate each key option in both a gain frame and a loss frame and check whether the preference survives. | OPERATIONALIZED | P5 |

# Analytical Procedure

1. **Reference point (P1).** State the reference point each party is using. Would a different, equally reasonable one change their view?
2. **Reframe (P5, P7).** Restate each option as a gain and as a loss. Does the preference flip?
3. **Loss aversion (P2).** Is the decision driven by avoiding a visible loss when the expected value favors acting?
4. **Certainty (P3).** Is a sure but smaller outcome being preferred out of proportion? Or is a gamble being taken to avoid a sure loss?
5. **Decomposition (P4).** How has the choice been split up? Would combining or separating components change it?
6. **Estimates (P6).** Check the probabilities used for anchoring and representativeness.

# What This Framework Pays Attention To

- Reference points and framing
- Asymmetry between losses and gains
- Probability weighting

# What This Framework May Underweight

- Organizational, political, and competitive dynamics
- Situations where the "biased" choice is rational given unmodeled constraints, such as survival

# Questions to Ask

- Would we choose differently if the same numbers were described the other way?
- What are we treating as the status quo, and why?
- Are we taking a bad gamble to avoid admitting a loss?
- Are we paying too much for certainty?
